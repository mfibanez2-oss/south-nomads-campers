# South Nomads Campers

Bilingual (ES/EN) static marketing site for South Nomads Campers — 4x4 camper truck rentals in Puerto Varas, Chile, for the Carretera Austral and Chilean Patagonia.

Plain HTML/CSS/vanilla JS, no build step, hosted on GitHub Pages.

- `en/`, `es/` — page content, mirrored 1:1 across both languages
- `shared/` — CSS, JS, JSON data (pricing, reviews, FAQ), and images shared by both languages
- `docs/content-editing-guide.md` — how to update prices, reviews, and FAQ content without touching code
